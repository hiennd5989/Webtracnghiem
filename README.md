# Web trắc nghiệm Tin học lớp 3 (HKII)

Trang web tĩnh ôn tập học kì II môn Tin học – lớp 3 (Trường Tiểu học Đại Từ, năm học 2025–2026).

## Tính năng

- 16 câu hỏi trắc nghiệm phần lý thuyết, mỗi câu có 3 đáp án.
- Bấm **Nộp bài** để chấm điểm trên thang 100 (mỗi câu 6,25 điểm).
- Đáp án đúng được tô xanh, đáp án sai được tô đỏ và hiển thị đáp án đúng.
- Nút **Làm lại** để làm lại từ đầu.
- Giao diện thân thiện, chạy được trên điện thoại.

## Cách chạy

Mở trực tiếp `index.html` trong trình duyệt, hoặc dùng một HTTP server đơn giản:

```bash
python3 -m http.server 8000
```

Sau đó mở `http://localhost:8000` trong trình duyệt.
